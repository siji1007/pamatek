<h1>PAMATEK</h1>
Ang application na ito ay naglalaman ng mga impormasyon hinggil sa mga pamahiing kaugnay sa pangingisda. Lahat ng datos ay nakalap mula sa mga isinagawang pananaliksik. Layunin ng application na ito na mabilis na maipamahagi sa mga mangingisda ng bayan ng Mercedes ang iba’t ibang pamahiing may kaugnayan sa kanilang hanapbuhay.
